How to run the test

  1. Pick the test color (orange 230, 140, 40 or grey 128, 128, 128). Keep zoom at 100 %.
  2. Look at each square for a few seconds. Is it equally light, equally saturated and equally large?
  3. Move the sliders until the square on white looks the same as the one on black. Note the values.
  4. Take a screenshot of the stage with the matched values visible.
